# Noura Health AI

PROMPT 1A.1 — FRONT-END (NOURA AI)



Create a world-class premium mobile application called Noura AI, built for iOS and Android, focused on helping users lose weight, gain muscle, maintain weight, eat healthier, stay hydrated and simplify meal planning using Artificial Intelligence.



The app must feel like a product created by Apple-level designers: extremely clean, elegant, premium, modern and intuitive.



This is NOT a fitness app.



This is an AI Nutrition Assistant.



Everything must be optimized for users in the United States (English US) first, while the architecture supports localization for Portuguese and other languages later.

AI FOOD RECOGNITION



Implement an AI pipeline that analyzes meal images.



Workflow:



1. User captures or uploads a food photo.

2. Validate image quality.

3. Compress image if necessary.

4. Send image to the AI recognition service.

5. Return structured nutritional information.



Response structure:



- Food name

- Estimated serving size

- Calories

- Protein

- Carbohydrates

- Fat

- Fiber

- Confidence score



Allow users to manually adjust results before saving.



---



BARCODE LOOKUP



Support barcode scanning for packaged foods.



Workflow:



- Read barcode.

- Look up nutritional information from the configured food database.

- Display serving information.

- Allow custom serving sizes.

- Save directly to the meal history.



If no product is found, allow manual entry and optionally submit it for future enrichment.
